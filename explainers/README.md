# Explainers

Diagrams for each BULSHY.FM build, as local HTML pages (open in a browser) plus a 1080x1920 image for the videos.

> **New to this?** Open the repo with an AI coding agent (Claude Code, Cursor, GitHub Copilot or
> similar) and ask it to explain a diagram next to the code it describes, for example: *"Walk me
> through build-01-car-racing-ppo.html using car-racing/train.py."*

- [build-01-car-racing-ppo.html](build-01-car-racing-ppo.html): how PPO learns Gymnasium CarRacing, and where the reward is used.
